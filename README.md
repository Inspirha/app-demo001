# Transferencia de propiedad · Dashboard SUNARP

Dashboard de Transferencias de propiedad y Compraventa predial SID (SUNARP).

- `index.html` — dashboard listo para publicar (datos incrustados).
- `index.template.html` — plantilla editable.
- `build.py` — regenera `index.html` desde los Excel de `datos/` (`python build.py`).
- `datos/` — archivos Excel originales de SUNARP.
